# Análisis de Ventas de Bicicletas

## Descripción del proyecto
Este proyecto tiene como objetivo analizar datos históricos de ventas de bicicletas para identificar patrones de compra, productos más vendidos y tendencias comerciales que permitan apoyar la toma de decisiones.

## Objetivo
Responder las siguientes preguntas:
- ¿Qué tipo de bicicleta se vende más?
- ¿Qué grupo de clientes compra con mayor frecuencia?
- ¿Existen tendencias por fecha o temporada?
- ¿Qué comportamiento futuro podría proyectarse con base en los datos históricos?

## Comprensión del negocio
Una empresa del rubro de bicicletas desea mejorar sus ventas mediante decisiones basadas en datos. Para ello, necesita comprender qué productos tienen mejor desempeño y qué segmentos de clientes presentan mayor potencial de compra.

## Comprensión de los datos
El conjunto de datos incluye:
- Fecha de venta
- Tipo de bicicleta
- Cantidad vendida
- Precio
- Segmento de cliente
- Región

## Preparación de datos
Las actividades realizadas fueron:
- revisión de valores nulos
- corrección de formatos de fecha
- estandarización de nombres de categorías
- eliminación de duplicados

## Análisis realizado
Se aplicó análisis descriptivo para resumir ventas históricas e identificar tendencias por producto, región y segmento de cliente.

## Resultados principales
- La bicicleta de montaña presentó la mayor cantidad de ventas.
- El segmento joven-adulto fue el más frecuente.
- Se observó un aumento de ventas en primavera y verano.
